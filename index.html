Règles de confidentialité

Application : Dhikrs & Invocations · Éditeur : Lafia Entreprise · Dernière mise à jour : 25 septembre 2026

L'application Dhikrs & Invocations (ci-après « l'Application ») est éditée par Lafia Entreprise. Ces règles décrivent comment nous collectons, utilisons et protégeons vos données.

1. Données collectées

  • Compte (si vous vous connectez) : adresse e-mail, nom d'utilisateur, photo de profil Google (si connexion Google). Fournies via Firebase Authentication.
  • Données d'usage stockées dans Firebase : cours vidéos consultés, commentaires publiés, invocation quotidienne dernière vue, statut administrateur.
  • Données locales (sur votre appareil uniquement) : favoris d'invocations, historique de rêves interprétés, préférences (notifications).
  • Identifiants publicitaires : votre Advertising ID Android est utilisé par Google AdMob pour la personnalisation des annonces.
  • Aucune donnée sensible (santé, biométrie, localisation précise) n'est collectée.

2. Utilisation des données

  • Vous authentifier et sécuriser votre compte
  • Personnaliser votre expérience (favoris, historique, compteurs)
  • Modérer les commentaires publiés
  • Afficher des publicités pertinentes pour financer l'application

3. Services tiers

L'Application utilise :

  • Firebase (Google) — authentification, base de données Firestore. Politique Google
  • Google AdMob — publicités. Politique AdMob
  • Google Sign-In — authentification optionnelle. Politique Google
  • DeepSeek / Grok / OpenAI (interprétation IA des rêves) — le texte du rêve saisi est transmis à ces API pour analyse. Aucune identification personnelle n'est envoyée.

4. Partage des données

Nous ne vendons aucune donnée personnelle. Les commentaires publics sont visibles par les autres utilisateurs sous votre nom d'utilisateur.

5. Conservation et suppression

Vos données sont conservées tant que votre compte est actif. Vous pouvez supprimer votre compte à tout moment depuis Profil → Supprimer mon compte. La suppression est immédiate et irréversible.

6. Vos droits (RGPD)

Vous disposez d'un droit d'accès, de rectification, d'effacement et de portabilité de vos données. Contactez-nous à l'adresse ci-dessous pour toute demande.

7. Enfants

L'Application n'est pas destinée aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de données d'enfants.

8. Sécurité

Les données sont stockées sur les serveurs sécurisés de Google Firebase avec chiffrement en transit et au repos.

9. Modifications

Nous pouvons modifier ces règles à tout moment. La date de dernière mise à jour figure en haut du document.
